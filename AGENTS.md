# Repository guidance

**TLDR:** Read [BRANDING.md](BRANDING.md) before changing Anyx visual output.

Use the supplied original `assets/brand/anyx-logo.png` and the byte-identical copies bundled with the three visual skills. Preserve its transparency and full proportions; do not recreate, recolor, crop or distort it. Keep the logo compact and secondary to project content. This guidance applies to visual artifacts, not unrelated text replies or the five nonvisual workflows.

Before delivering a branding change, verify that the output contains the actual original image and that installed skill archives retain it without binary normalization or repository/network dependencies. Run the relevant branding and portability tests. Keep rendered MP4 evidence separate from composition preparation.
